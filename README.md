Customer Sales SQL Analysis
Project Overview
This project uses SQL and SQLite to analyze customer sales data and generate business insights.
The analysis focuses on sales performance, product revenue, customer spending, regional performance, and high-value transactions.
Tools Used

SQL
SQLite
SQLite3 Editor
Visual Studio Code

Database Tables

Customers — customer information and regions
Products — product names, categories, and prices
Sales — transactions, quantities, and sale dates

Key Analysis
The project includes SQL queries for:

Overall sales metrics
Revenue by product
Sales by region
Monthly sales performance
Customer spending
High-value transactions
Sales classification using CASE
Multi-table JOIN analysis
Aggregation using COUNT, SUM, and AVG
